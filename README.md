# Descargas de ierwinx

Instaladores oficiales de las apps de [ierwinx.com](https://ierwinx.com), publicados en
[Releases](https://github.com/ierwinx/descargas/releases): un release por app y versión
(`ibridge-v1.0`, `wolfgit-v1.0.1`…).

**Este repositorio no contiene código fuente.** El «Source code (zip)» que GitHub agrega a cada
release solo trae este README.

Descarga siempre desde la página de cada app en [ierwinx.com](https://ierwinx.com): ahí está el
enlace oficial y el SHA-256 de cada instalador para comprobarlo.
